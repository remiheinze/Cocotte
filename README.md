# Cocotte — Market Intelligence

Site web de démonstration pour explorer les marchés américains, français et internationaux.

## Publication GitHub Pages
Dans GitHub, ouvrir **Settings → Pages**, choisir **Deploy from a branch**, sélectionner `main` et `/(root)`, puis enregistrer.

URL attendue : https://remiheinze.github.io/Cocotte/

## Données
Les cours, variations, volumes et indices affichés sont des exemples fictifs clairement signalés comme données de démonstration. Ils ne sont pas des cotations en direct. Les actualités sont des thèmes pédagogiques, pas un flux d'articles. Le site ne fournit pas de conseil en investissement et ne passe aucun ordre.

Une version connectée à des fournisseurs de données et à un modèle IA nécessite des comptes fournisseurs, des clés API stockées côté serveur et un backend sécurisé. Ne jamais placer de clé API dans le JavaScript du navigateur ou dans le dépôt public.
